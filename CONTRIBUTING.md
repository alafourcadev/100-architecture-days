# Contribuyendo a #100ArchitectureDays

Gracias por tu interes en contribuir.

## Como Contribuir

### Reportar Bugs
- Usa el template de Issue
- Incluye pasos para reproducir
- Adjunta logs si es relevante
- Especifica el dia afectado

### Sugerir Mejoras
- Describe la mejora claramente
- Explica por que seria util
- Propone una solucion si tienes una en mente

### Contribuir Codigo
1. Fork el repo
2. Crea una branch: `git checkout -b feature/mejora-dia-X`
3. Haz tus cambios
4. Agrega tests
5. Asegurate que todo compile: `mvn clean test`
6. Commit: `git commit -m "feat: mejora en dia X"`
7. Push: `git push origin feature/mejora-dia-X`
8. Abre un Pull Request

### Estandares de Codigo
- Codigo en ingles, comentarios en espanol
- Tests para todo cambio funcional
- Sigue el estilo del proyecto

### Lo que NO Hacer
- No hagas los ejercicios por mi (es MI journey)
- No cambies la estructura sin discutir primero
- No agregues dependencias innecesarias

## Code of Conduct

- Se respetuoso
- Acepta feedback constructivo
- Enfocate en el aprendizaje colaborativo
